# PloverAI has moved

PloverAI now lives at **[Translator-CATRAX/PloverAI](https://github.com/Translator-CATRAX/PloverAI)**.

PloverAI lets you ask a biomedical question in plain English. ARAX answers it over the NCATS Biomedical Data Translator's Tier 0 knowledge graph, and every claim in the explanation cites a fact.

This repository keeps the project's history up to 2026-10-09. The earlier chat interface for PloverDB (RTX-KG2.10.2c) is at commit `b37b3d4`, and the move to ARAX over Tier 0 at commit `9487aa9`. Development continues in the new repository, which carries the same history.
